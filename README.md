## Planejador de viagens ##

Este é uma aplicação em JavaScript desenvolvida para planejamento de viagens, que calcula:
1. Custo de combustível
2. Tempo de viagem
3. Divisão de despesas
4. Conversão de reais para dólares


Requisitos básicos:

- Node.js


Como rodar:

- Navegue, pelo terminal, até a pasta raiz do projeto `planejador-viagem`
- instale as dependências com o comando `npm install`
- por fim, inicie o programa com o comando `node planejador.js`
